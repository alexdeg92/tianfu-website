# Tianfu Website - Deployment Guide

## Quick Deploy to Vercel

### Option 1: Vercel Web Interface (Recommended)
1. Go to https://vercel.com/new
2. Select "Continue with GitHub"
3. Search for "tianfu-website" in your repositories
4. Click "Import"
5. Framework will auto-select as "Next.js"
6. Click "Deploy"
7. Your site will be live at: `https://tianfu-website.vercel.app`

### Option 2: Using Vercel CLI
```bash
npx vercel --prod
```
