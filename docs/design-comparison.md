# Tian Fu Website Design Comparison

## Claude Design Direction

Premium editorial restaurant treatment: sticky left rail on desktop, cinematic hero photography, deep ink background, restrained gold accents, high-contrast serif display type, smooth reveal animations, and menu cards that feel closer to a dining-room menu than a generic delivery grid.

Strengths used:
- Strong first-viewport brand signal with the Tian Fu wordmark and signature Sichuan dish.
- Sticky desktop sidebar with prominent ordering links.
- Scroll reveals, card lift, image zoom, drawer, and page fade transitions.
- Dense full-menu browsing with category anchors for repeat visitors.

## Google Stitch Alternative Direction

Stitch-style concept leaned more product-like: top navigation, broad content bands, pill filters, high-clarity ordering blocks, and simpler mobile information hierarchy.

Strengths used:
- Clear delivery platform cards.
- Horizontal category controls on the menu page.
- Utility-first content structure for location, hours, and contact.
- Mobile drawer pattern with direct links to all primary pages.

Note: the Stitch web surface was reachable, but no public generation endpoint was exposed from the available runtime. I incorporated the Stitch-style UX patterns manually while keeping the implementation production-ready.

## Final Blend

The shipped site blends Claude's upscale restaurant atmosphere with Stitch's practical navigation and ordering clarity. The result is a multi-page Next.js site with premium visual direction, real optimized Tian Fu assets, SEO metadata per page, and smooth motion without making the restaurant feel like a template.
